# **App Name**: NeuroSharp

## Core Features:

- Stroop Test Module: Implement the classic Stroop effect game where users identify ink color of conflicting color names to train focus.
- Mental Math Rush: Timed arithmetic problems (+, -, ×, ÷) with decreasing time per question to improve cognitive speed and calculation skills.
- Pattern Recall Game: A grid-based game where users recall and tap specific tiles that flash on a 4x4 grid to enhance short-term memory.
- Schulte Table Challenge: A 5x5 grid of randomized numbers from 1-25 that users tap in ascending order to improve peripheral vision and processing speed.
- Performance Tracking & Analytics: Save and display user high scores, daily progress, 'Brain Score' points, and daily streak counts using local storage.
- Offline Functionality: Ensure all game modules and performance tracking work fully without an internet connection, utilizing local logic and storage.

## Style Guidelines:

- Primary color: A vibrant yet calming blue (#2662D8), evoking intelligence, focus, and clarity.
- Background color: A very light, subtle blue (#E6EDF3) that supports readability and a clean interface without distraction.
- Accent color: An invigorating aqua (#17A9CC), providing contrast for calls to action and highlighting key information.
- Headline and body font: 'Inter', a clean, modern sans-serif chosen for its objective, neutral appearance and excellent readability in an app focused on cognitive tasks.
- Utilize simple, geometric line-art icons that communicate meaning clearly and align with the app's minimalist, brain-training theme.
- A minimalist and uncluttered layout focusing on one game or task at a time, minimizing distractions to enhance user focus during exercises.
- Smooth, subtle transitions for game entry/exit, prompt visual feedback for correct/incorrect answers, and elegant progress bar animations for gamification elements.
